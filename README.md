# Image Filtering Coursework

MATLAB implementation and report for an engineering mathematics project on image filtering.

## Files

- [code.m](code.m): MATLAB implementation.
- [EngMath_Project.pdf](EngMath_Project.pdf): project report.

## Running

Read the report, inspect the image inputs and paths used by `code.m`, and supply the required images before running it in MATLAB. Review the script for toolbox requirements. Input images and a tested MATLAB/toolbox version list are not packaged here.

The report provides the context for interpreting the implementation and its results. This is educational work.
